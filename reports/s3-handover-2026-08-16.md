## The open decision (R34) — blocks freeze

**L3 is not reliably measurable on any affordable family, and the cause is not a
threshold.** Across the corpus the binding constraint is the *total absence* of
citations (59–100% of reviews), not the ≥3 count (0–3%) or the ≥2-instrument
rule (1–14%). Decisively: **the near-miss transcript cites zero ids**, so L3 as
operationalised would score the corpus's most interesting epistemic event as
ungrounded.

Recommendation on the table, awaiting Nick:

1. **L1/L2 primary** — citation-free, measurable on every family including haiku.
2. **L3 secondary**, reported only alongside the family's measured capability.
3. **Exploratory judge-scored "argued grounding" (L3ᵃ)** — rationale names
   instruments and statistics without citing ids. Pre-register as exploratory.
4. **Do not buy sonnet purely to rescue L3** (24% pass rate, ~16× the cost).

This does **not** invalidate existing nulls: L1 needs no citations and is zero
everywhere. It is a latent threat that bites only if something moves.

## The lesson worth carrying forward

Two defects this session (F21 denominator, F22 jitter scale) were in apparatus
added this same week, and both surfaced because a *run* failed, not because a
test failed. Code on the failure path executes only when something fails, so its
defects are systematically under-detected — 215 green tests said nothing about
whether the retry chain took 3 ms or 7 s. Every threshold, denominator and
backoff constant added for robustness needs a test that pins its **magnitude**,
not merely its behaviour. And F13's principle applies to our own instruments as
much as to the worlds: build in impossible-value checks. The 400% failure rate
is what exposed F21.

Related: R32's threshold was set from a single observation, which then declared
that observation admissible. Six further runs contradicted it. Do not set an
admissibility criterion from one data point.
